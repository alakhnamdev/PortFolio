Weather Application Overview

This Weather Application is a modern, dynamic web app designed to deliver real-time weather updates with a clean, responsive user interface. Developed using Next.js, styled with Tailwind CSS, and integrated with WeatherAPI.com, it ensures reliable and accurate weather data for users across the globe.

Key Features:

  • Current Weather Data: Displays temperature, humidity, condition, and wind speed for any searched location.
  • 3-Day Weather Forecast: Offers weather predictions for the upcoming three days.
  • 24-Hour Hourly Data: Showcases hourly weather information including temperature and conditions.
  • Sunrise & Sunset Timings: Provides accurate sunrise and sunset times for the selected location.
  • Wind Speed & Direction: Displays real-time wind speed along with directional data.
  • Animated Visual Feedback: Integrated with LottieFiles for clean, lightweight weather animations enhancing user experience.
  • Responsive Design: Fully optimized for desktop, tablet, and mobile devices using Tailwind CSS.
